# Waiter Character Guide

Use the attached reference image as the visual basis for all waiter characters.

## Core cast
1. **Jacques**
   - Tall waiter
   - Wears a top hat
   - Shot framing: camera slightly low so the top of his hat is cropped out of frame

2. **Marco**
   - Round middle waiter
   - Shot framing: fits comfortably inside the frame

3. **Gus**
   - Short waiter
   - Shot framing: camera slightly higher so there is visible space above his head

## Shared environment
- Warm elegant restaurant interior as the baseline setting
- Playful tone
- Instantly readable composition
- Suitable for a fast music video
- Allow scene-specific location variants when defined in the shot list (for example: outdoor grill, curry-house dining)

## Presence rule for every shot
Use exactly the waiter(s) specified in each shot brief.
If a shot names a single waiter, no other waiters are present.
If a shot names multiple waiters, include only that listed combination.
